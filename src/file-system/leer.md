# Utilizar modulo File System de Node

## Presentación
Nos permite manejar archivos desde el lenguaje, pudiendo leer, editar, borrar, etc.
El modulo de file System de Node JS es nativo y su importación no require de instalación más que la de NODE JS.

## Archivos

Los archivos de ejemplo son los siguientes:

1. <b>WriteFile.js<b>: EJemplo para escribir un archivo.
2. <b>readFIle.js<b>: Ejemplo para leer un archivo.
3. <b>EditFile.js<b>: Ejemplo para editar un archivo.
4. <b>DeleteFile.js<b>: Ejemplo para borrar un archivo. Se recomienda prestar atencion a la carpeta para ver como se crea un archivo y luego se borra.

## !IMPORTANTE!
Para que pueda funcionar los metodos de FS, creados en el repositorio, debes crear en la misma carpeta que se encuentra este archivo .md una carpeta llamada 'files'. Sino algunos metodos no funcionaran con exito.
